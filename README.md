# Cronometro Inteligente

Cronometro de treinos **Fim de Papo**, publicado em:

https://cronometro-inteligente.netlify.app/

## Conteudo

- `index.html`: interface, estilos e logica do cronometro.
- `audios.json`: manifesto dos alertas sonoros.
- `meme.mp3/`: arquivos de audio usados pelos alertas.

Abra `index.html` por um servidor local ou publique a pasta na Netlify.
